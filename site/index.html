Azure Data Engineering

Azure End-to-End Data Engineering Pipeline (Medallion Architecture)

Sep 2026

End-to-end Azure data platform on the AdventureWorks dataset (10 source files, 3 years of sales data) using a Bronze/Silver/Gold medallion architecture on ADLS Gen2. A metadata-driven ADF pipeline ingests all 10 files through 1 reusable dataset; Databricks PySpark writes 8 Silver tables as Parquet; Synapse serverless SQL serves the Gold layer to Power BI.
